# 纠结擂台

一个手机竖屏优先的轻量网页小游戏：输入两个日常选项和各自理由，系统将语句转化为角色属性与技能，让双方自动进行六回合较量。胜负公布后，玩家可以接受判决，也可以点击“我不服”直接改判；反悔本身就是偏好测试。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

## 验证与构建

```bash
npm test
npm run build
npm run preview
```

## 生成机制

- 本版不调用外部 API，也不需要后端。
- 属性、角色名和四项技能由本地关键词、时间压力、表达具体度与情绪倾向等规则生成。
- 输入会生成固定种子；相同输入得到相同角色与战斗结果。
- 通用战斗固定六回合，双方至少各行动两次；首发演示固定为 B 在第六回合险胜。

## 使用边界

仅用于吃什么、是否出门、早睡还是刷手机等低风险日常选择，不用于医疗、投资、法律等重大决策。
