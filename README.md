# 纠结擂台 Web MVP

《变量序列01》手机竖屏网页小游戏：让两个日常选项变成角色打一架，再用“我不服”测试真实偏好。

## 运行

双击 `启动纠结擂台.bat`，它会启动本地服务并自动打开网页。

也可以在当前目录手动运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

也支持直接双击 `index.html` 运行；推荐使用启动脚本，以获得更稳定的资源加载体验。

## 已实现

- 问题、A/B 选项及理由输入
- 基于关键词、时间压力、成本和情绪的本地属性生成
- 自动角色命名、五项属性解释及每方两个技能
- 带固定随机种子的六回合自动战斗
- 接受判决与“我不服”直接改判
- 反悔速度分析及 1080×1440 PNG 战报下载
- 360–430px 手机竖屏优先，桌面浏览器显示手机容器

核心规则分别封装在 `generator.js` 与 `battle-engine.js`，方便后续将前者替换为大模型接口。
